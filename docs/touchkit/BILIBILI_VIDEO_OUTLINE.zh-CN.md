# B 站介绍视频提纲

建议在 Draft PR 固定代码版本后录制，视频中注明测试包版本或提交号。

## 6～8 分钟结构

1. **问题与效果（0:00～0:40）**
   - 手机触屏操作 PC 游戏时，传统触摸板和固定虚拟键盘不够顺手。
   - 先展示成品：移动鼠标、按住左键同时滑动、组合键、轮盘和摇杆。
2. **开启方式（0:40～1:30）**
   - 设置 > 云游戏操作。
   - 解释“云游戏模式”和“显示悬浮按键”互相独立。
   - 展开其他项目，展示线性移动、灵敏度、不透明度和“禁用触摸手势”。
3. **编辑布局（1:30～3:20）**
   - 拖动控件、轻点编辑、调整大小和形状。
   - 展示 `F1=冒险之证`、`Ctrl+C=复制`、`Num1` 和左右 Ctrl。
   - 展示鼠标键、滚动步幅、锁定和定时长按。
4. **轮盘与摇杆（3:20～4:30）**
   - 新建空轮盘，填写 4 个方向，按住展开并滑动选择。
   - 修改摇杆或方向键的四向绑定，松手后确认释放。
5. **游戏布局与迁移（4:30～5:40）**
   - 新建并重命名两套布局。
   - 重新进入同一游戏，展示自动恢复上次布局。
   - 从一台设备导出 JSON，在另一台设备导入为新布局。
6. **边界与参与测试（5:40～结束）**
   - 不需要系统悬浮窗权限，不修改 Moonlight 串流协议。
   - 跨比例设备可能需要微调位置；暂不迁移全部 Artemis 设置。
   - 给出仓库、Draft PR、测试 APK 和问题反馈入口。

## 录制前检查

- 使用干净布局，避免测试残留控件遮挡画面。
- 打开触摸显示或后期加触点标记，让双指操作可见。
- 同时录制一段实际串流画面和设置/编辑器画面。
- 隐藏主机 IP、设备标识、通知和账号信息。
- 用固定提交生成 APK，避免视频与 PR 中的界面不一致。
